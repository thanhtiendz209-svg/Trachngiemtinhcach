# Trắc nghiệm tính cách

Mã nguồn website được sao chép từ dự án Testtinhcach để tiếp tục phát triển độc lập trong Trachngiemtinhcach.

Bản sao bao gồm mã nguồn, hình ảnh, dữ liệu câu hỏi, cấu hình và các công cụ của dự án. Các bản build, nhật ký, ảnh chụp kiểm tra và tệp đính kèm/sao lưu của dự án gốc không được đưa vào.

## Phát triển

Cài các phụ thuộc bằng `npm ci`, chạy môi trường phát triển bằng `npm run dev`.

Kiểm tra kiểu bằng `npm run typecheck`, chạy kiểm thử bằng `npm test`, và tạo bản build bằng `npm run build`.
